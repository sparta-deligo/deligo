# Project Overview (프로젝트 개요)
- 프로젝트명 : DeliGo
- 배경 : 배달 어플리케이션 개발에 대한 아웃소싱 프로젝트를 맡게 되었다는 가정
- 설명 : 간단한 배달 어플리케이션의 Backend 서버를 SpringBoot를 통해 구현

# Key Features (주요 기능)
- 회원가입 및 로그인
- 가게 생성 및 관리
- 메뉴 생성 및 관리
- 주문 생성 및 관리
- 리뷰 생성 및 관리
  - 리뷰에 대한 사장님 댓글 작성 및 관리
- 가게 검색
  - 가게명으로 검색
  - 인기 검색어 조회
